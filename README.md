# comparing_llms_and_human_codes

This directory structure organizes files for a project that compares code generated by different Large Language Models (LLMs) to human-written code for the "Search Insert" problem.

## Directory Structure

The repository is organized as follows:

-   **easy/**, **medium/**, and **hard/**: These directories contain description files for the "Search Insert" problem, likely categorized by difficulty. The `vvv` files are currently of unknown purpose.
    -   **easy_descr_binary_search.txt**: Description of the "Search Insert" problem (Easy difficulty).
    -   **medium_descr_binary_search.txt**: Description of the "Search Insert" problem (Medium difficulty).
    -   **hard_descr_binary_search.txt**: Description of the "Search Insert" problem (Hard difficulty).
    -   **vvv**: (Purpose unclear, requires further investigation)

-   **Deepseek_Outputs/**, **Gemini_Outputs/**, and **GPT_Outputs/**: These directories contain code generated by the respective LLMs. Each LLM's output is further organized by problem difficulty.
    -   Each LLM directory contains:
        -   **easy/**, **medium/**, and **hard/**: Subdirectories for each difficulty level.
        -   Within each difficulty subdirectory:
            -   **easy_searchInsert.py** / **medium_searchInsert.py** / **hard_searchInsert.py**: Code generated by the LLM for the "Search Insert" problem.
            -   **human_searchinsert.py**: Human-written code for the "Search Insert" problem (presumably for comparison).
            -    **vv**: (Purpose unclear, requires further investigation)

## Purpose

The directory structure suggests that this project aims to:

1.  Generate code for the "Search Insert" problem using different LLMs (Deepseek, Gemini, GPT) across varying difficulty levels.
2.  Compare the LLM-generated code with human-written code for the same problem.
3.  Evaluate the performance and quality of the LLM-generated code against human code.
